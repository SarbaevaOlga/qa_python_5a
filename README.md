# qa_python_5a
Автотесты написаны для сервиса Stellar Burgers. Это космический фастфуд: можно собрать и заказать бургер из необычных ингредиентов.
Покрыть тестами:
1) Вход :
- по кнопке «Войти в аккаунт» на главной,
- через кнопку «Личный кабинет»,
- через кнопку в форме регистрации,
- через кнопку в форме восстановления пароля.
2) Переход в личный кабинет :
- переход по клику на «Личный кабинет».
- Переход из личного кабинета в конструктор 
- Переход по клику на «Конструктор» и на логотип Stellar Burgers.
3) Выход из аккаунта
- по кнопке «Выйти» в личном кабинете.
4) Раздел «Конструктор»
- работают переходы к разделам:«Булки», «Соусы», «Начинки».

- тесты написаны с использованием Selenium и VS Code
